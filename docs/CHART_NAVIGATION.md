# Chart navigation

- Drag the price plot to move left/right and up/down; vertical movement unlocks automatically.
- Scroll over the plot to zoom time around the pointer. Horizontal trackpad movement pans time.
- Shift + scroll, or scroll over the right axis, changes candle height.
- The +/− buttons change candle width; HEIGHT +/− changes candle height.
- Drag the price/time axis to scale it; double-click an axis to reset its scale.
- Drag the separator between indicator panes to resize them. Enabled panes remain present if a live flow response is temporarily empty.
- RESET restores automatic price scaling and the recent view. FIT ALL shows loaded history; LIVE returns to the latest bar.
- Focus the chart for +/−, left/right arrows, and up/down arrows (candle height).
- EXPAND gives the chart the window; lower panes fit inside the available space.

Validated on http://127.0.0.1:5174/onchain with browser wheel zoom, ordinary two-axis drag, both height controls, pane-separator drag, RSI visibility, and reset. Automated suite: 1,251 tests.
